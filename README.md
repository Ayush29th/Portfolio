# 🌐 Personal Portfolio

A responsive personal portfolio website designed to showcase my skills, projects, and development journey. It serves as a central platform to highlight my work and provide an overview of my technical capabilities.

## 🚀 Features
- Clean and responsive design  
- Sections for About, Skills, and Projects  
- Smooth navigation and user-friendly interface  
- Showcases projects with details  
- Contact section for easy reach  

## 🛠️ Technologies
- HTML  
- CSS  
- JavaScript  

## ⚙️ Running the Project
git clone https://github.com/Ayush29th/Portfolio.git  
cd Portfolio  
Open index.html in your browser
